"Take all the individual elements/properties from this thing and spread them out here."

It works differently depending on whether you're using an array or an object.

1. With arrays
let arr1 = [1, 2, 3];

let arr2 = [...arr1];

...arr1 spreads:

[1, 2, 3]
 ↓
 1, 2, 3

So:

arr2 = [1, 2, 3];

Without spread:

let arr2 = [arr1];

you get:

[[1, 2, 3]]

because the entire array becomes one element.

2. With objects

This is what you're using in your code.

let user = {
    name: "Om",
    age: 20
};

let newUser = {
    ...user
};

...user spreads the properties:

{
    name: "Om",
    age: 20
}

So newUser becomes:

{
    name: "Om",
    age: 20
}
3. You can add more properties
let newUser = {
    ...user,
    city: "Vadodara"
};

Result:

{
    name: "Om",
    age: 20,
    city: "Vadodara"
}
4. You can override properties
let newUser = {
    ...user,
    age: 21
};

Result:

{
    name: "Om",
    age: 21
}

Because the later age: 21 overrides the age: 20 that was spread earlier.4

PASSPORT.JS AUTHENTICATION + SESSION NOTES
==================================================

Passport.js is an authentication middleware for Node.js/Express.

It helps handle:
- Login
- User authentication
- Sessions
- Maintaining logged-in users

--------------------------------------------------
1. PASSPORT INITIALIZE
--------------------------------------------------

Code:

app.use(passport.initialize());

Function:
- Initializes Passport in the Express application.
- Makes Passport ready to handle authentication.
- Required before using Passport authentication methods.

Think:
"Start Passport and make it ready."

--------------------------------------------------
2. PASSPORT SESSION
--------------------------------------------------

Code:

app.use(passport.session());

Function:
- Connects Passport with Express sessions.
- Maintains the user's login across multiple requests.
- Allows Passport to restore the logged-in user.
- Makes the authenticated user available through:

req.user

IMPORTANT:
passport.session() should come AFTER the Express session middleware.

Example:

app.use(session(sessionOptions));

app.use(passport.initialize());
app.use(passport.session());

--------------------------------------------------
3. LOCAL STRATEGY
--------------------------------------------------

Code:

passport.use(new LocalStrategy(User.authenticate()));

NOTE: CORRECT SPELLING IS LocalStrategy, NOT LocalStratergy.

Function:
- Tells Passport to use username/password authentication.
- LocalStrategy is used when authentication is performed using
  credentials stored in our own database.
- User.authenticate() checks whether the username and password
  are correct.

Flow:

username + password
        ↓
LocalStrategy
        ↓
User.authenticate()
        ↓
Check database
        ↓
Correct → Login successful
Wrong   → Authentication failed

--------------------------------------------------
4. SERIALIZE USER
--------------------------------------------------

Code:

passport.serializeUser(User.serializeUser());

Meaning:
Serialize = User → Store user ID in session

After successful login, Passport does NOT normally store the
entire user document in the session.

Instead, it stores a unique identifier, usually the user's _id.

Example User:

{
    _id: "abc123",
    username: "om",
    email: "om@gmail.com"
}

Session stores approximately:

user = "abc123"

Purpose:
- Converts the logged-in user into a small piece of information
  that can be stored in the session.
- Usually stores the user's ID.

Easy meaning:

"Which information about the user should I store in the session?"

--------------------------------------------------
5. DESERIALIZE USER
--------------------------------------------------

Code:

passport.deserializeUser(User.deserializeUser());

Meaning:
Deserialize = Session User ID → Complete User

When a new request comes in, Passport gets the user ID from
the session.

Example:

Session:
user = "abc123"

Then:

deserializeUser()
        ↓
Find user with ID "abc123" in database
        ↓
Get complete user document
        ↓
req.user


Example:

req.user = {
    _id: "abc123",
    username: "om",
    email: "om@gmail.com"
}


Easy meaning:

"I have the user's ID from the session.
Now find the complete user from the database."


--------------------------------------------------

--------------------------------------------------

Username: om
Password: 123456

        ↓

passport.authenticate("local")

        ↓

        ↓

        ↓

        ↓

--------------------------------------------------

--------------------------------------------------
8. MEANING OF EACH LINE
--------------------------------------------------

app.use(passport.initialize());

→ Initialize Passport.


app.use(passport.session());

→ Enable Passport authentication using sessions.


passport.use(new LocalStrategy(User.authenticate()));

→ Use username/password authentication and verify credentials
  using User.authenticate().


passport.serializeUser(User.serializeUser());

→ Store the user's ID in the session after successful login.


passport.deserializeUser(User.deserializeUser());

→ Use the ID stored in the session to retrieve the complete
  user from the database.

JWT HAS THREE PARTS
HEADER(encoding).PAYLOAD.SIGNATURE
🔹 Encoding

Converts data into a different format for storage or transmission. It provides no security.

Example:
Hello → SGVsbG8= (Base64)

🔹 Encryption

Converts readable data (plaintext) into unreadable data (ciphertext) to provide confidentiality. It can be reversed using the appropriate key.

Example:
Hello → X7a9@2... → Hello

🔹 Hashing

Converts data into a fixed-length hash mainly for verification and integrity. It is designed to be one-way.

Example:
Hello → 185f8db3...

🧠 Remember

Encoding = Format
Encryption = Secret 🔒
Hashing = Fingerprint #️⃣


Short Note: bcrypt.hash(this.password, 12)
bcrypt.hash(this.password, 12)
bcrypt → Library used for secure password hashing.
hash() → Converts the password into a one-way hash.
this.password → The user's original password.
12 → Cost factor/salt rounds; higher values require more computation.

Example:

"hello123"
    ↓
bcrypt.hash("hello123", 12)
    ↓
"$2b$12$..........."

🔑 Password → Hash → Store in database
The original password is not stored and the hash is not decrypted.
